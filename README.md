# GitHub Uploader

From AI-generated projects to ready-to-use Android apps and websites — directly from your phone.

GitHub Uploader is a free and open-source Android application that makes uploading, building, and publishing projects incredibly simple.

Have you ever used AI coding tools like Claude, ChatGPT, or other AI assistants to create an Android app or website, only to end up with a ZIP file and no idea how to turn it into something you can actually use?

That's exactly the problem GitHub Uploader was built to solve.

Instead of manually uploading files, configuring GitHub repositories, setting up build environments, and dealing with complicated deployment processes, you can do everything directly from your Android phone.

Create with AI. Upload with one tap. Build, publish, and test.

---

##  ✨Features

📱 Build Android APKs from ZIP files

Turn AI-generated projects into installable Android applications using GitHub Actions.

Supported project types include:

- Native Android projects (Gradle).
- Flutter projects.
- Capacitor projects.
- HTML, CSS, and JavaScript websites (automatically packaged into Android apps).

The application detects supported project structures and generates the appropriate GitHub Actions workflow to build your APK in the cloud.

When the build finishes, you can download the APK directly to your phone.

##  🌐 Publish HTML Websites

Have an AI-generated website? Publish it using GitHub Pages.

- Upload complete website projects as ZIP files.
- Upload individual HTML files.
- Publish websites using free GitHub Pages hosting.
- Get a public URL to share your website.
- Update existing websites without starting over.

##  📦 Simple Project Uploads

- Create new GitHub repositories.
- Upload ZIP files directly.
- Update existing repositories.
- Choose between public and private repositories where supported.
- Replace existing project files when needed.
- Automatically configure APK build workflows.

##  📚 Project Library

Manage your uploaded projects directly from the application.

- Browse your GitHub repositories.
- Download previously generated APKs.
- Open published websites.
- Access project files.
- Rename or delete repositories.
- Manage and update individual files.

##  🔄 Automatic APK Builds

GitHub Actions handles the building process in the cloud, so you don't need Android Studio or a local development environment.

The application also supports automated APK signing when the required signing secrets are available.

##  🚀 How to Use

You only need three simple steps to turn an AI-generated project into an Android application:

Step 1 — Create your project

Use Claude, ChatGPT, or any AI coding assistant to generate an Android application project.

Download the generated project as a ZIP file.

- Step 2 — Upload your project

Open GitHub Uploader, sign in with your GitHub account, select Upload App (APK), choose your ZIP file, and give your project a name.

- Step 3 — Download and install

GitHub Actions will automatically build your project. Once the build is complete, you can download the generated APK directly to your phone and install it.

That's it!

---

##  🔐 Getting Started

1. Install and open GitHub Uploader.
2. Sign in using your GitHub account.
3. Follow the in-app instructions to configure your GitHub OAuth application and enable Device Flow.
4. Authorize the requested GitHub permissions.
5. Start uploading your projects!

The application also provides an advanced login option using a GitHub Personal Access Token.

---

##  ⚙️ Requirements

- An Android device.
- A GitHub account.
- An internet connection.
- A supported project structure for APK generation.

Important notes:

- APK builds run on GitHub Actions and may take several minutes.
- Build success depends on the project's structure and dependencies.
- GitHub Pages hosting requires a public repository when using the free hosting option.
- Published websites are publicly accessible, including their source files.
- GitHub Actions usage limits and GitHub policies apply.
